이 브랜치는 원격 `main`의 `093016a864ad0e2c4311240fd18e2f6a830d5747`에서 분리했다. 원래 작업 브랜치에 연결된 이전 작업의 미푸시 커밋 3개를 함께 올리지 않는다. 원본 구현 커밋은 `303fe2bb2212a4e43d58b8f12e1bb4a282912bf0`, 적용 기록 커밋은 `4d3c41fd2c0548e3f5ecf0e97f7ec2a6fbc66c7e`이며 로컬 원본은 그대로 보존한다.

브랜치 `work/vibox-backend-performance-20261028`의 Git 자동 배포는 루트 `vercel.json`에서 제외했다. 이 설정은 [Vercel 공식 Git 설정](https://vercel.com/docs/project-configuration/git-configuration#gitdeploymentenabled)을 따른다. 다른 브랜치의 배포 설정과 원격 `main`은 변경하지 않는다.

현재 프런트는 `20261028-front-perf-r2`이며 준비 후보 `20261028-front-box-perf-r3`는 계속 사용자 보류 상태다. 이번 보관·푸시 과정에서는 프런트 수정·배포와 서버 변경을 수행하지 않는다. 소스 해시가 동일한 기존 검증을 재사용하며 앱 테스트·빌드를 다시 실행하지 않는다. 실제 사용자 계정의 전체 파일 흐름, 운영 지연 전후 비교, 운영 rollback, Galaxy/One UI·Safari QA는 미검증 상태를 유지한다.
